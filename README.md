# Campus Student Planner

## About
Campus Student Planner is a website that helps college students
keep track of their assignments and weekly class schedules.

## Features
- Home dashboard
- Assignment tracker
- Search and add assignments
- Mark assignments as completed
- Weekly class schedule
- Live weather information
- Upcoming public holidays

## Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- GitHub Pages

## APIs Used
- Open-Meteo API for weather information
- Nager.Date API for public holidays

## How to Use
Open the website and use the navigation buttons to switch
between Home, Assignments, and Schedule.

## Project Status
